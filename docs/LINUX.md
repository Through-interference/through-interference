# Linux

Linux является основной платформой. Полная инструкция от чистого checkout, схемы подключения, can-utils, GUI через UART, первая настройка плат и демонстрация находятся в [README](../README.md).

Краткий запуск из подготовленной папки проекта:

| Подключение | Команда |
| --- | --- |
| USB наземного ESP32 | `./start-ground.sh` |
| CANable со стороны борта | `./start-air.sh --can-channel can0` |
| Оба конца стенда на одном компьютере | `./start-demo.sh --port /dev/ttyUSB0 --can-channel can0` |
| Автоматическая проверка обоих направлений | `./start-demo.sh --port /dev/ttyUSB0 --can-channel can0 --demo` |
| GUI через USB-UART земли | `./start-panel.sh` |

Порты и CAN-интерфейс нужно выбрать по фактическому подключению. При нескольких ESP32 порт земли задаётся явно. В терминальной консоли ground/air команда `send 00010203` отправляет на другую сторону; в bench используются `pc` и `bvs`.

SocketCAN можно использовать напрямую:

```bash
./setup-can.sh can0 500000
candump -tz can0
```

В другом терминале:

```bash
cansend can0 123#00010203
```

Для получения этого сообщения на земле должен работать ground или GUI. Локальный вывод candump после cansend не является подтверждением прохождения радио.
