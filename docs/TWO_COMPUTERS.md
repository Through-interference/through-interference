# Обмен Windows ↔ радио ↔ CAN ↔ Mac

Windows работает со стороны земли. Mac с CANable заменяет CAN-узел БВС.
Прошивки менять не нужно. CAN работает со скоростью 500000 бит/с.

```text
Windows ↔ USB ↔ наземный ESP32 TX ↔ радио ↔ бортовой ESP32 RX ↔ VP230 ↔ CANable ↔ USB ↔ Mac
```

## Что подключить

1. На Mac оставить CANable и бортовой ESP32 с CAN-модулем. USB бортового ESP32 нужен для питания, консоль его не открывает.
2. CAN-H/CAN-L/GND CANable оставить соединёнными с CAN-модулем борта. Проводку TX → D4, RX → D17 и питание модуля 3.3 V сохранить.
3. Наземный ESP32, который на Mac определялся как `/dev/cu.usbserial-10`, отключить от Mac и подключить USB-кабелем к Windows. На нём нет CAN-модуля.
4. Закрыть панель и прежние консоли, использующие USB-порт или CANable. Питание и антенны нужны обоим радиомодемам.

Интернет между компьютерами не нужен. При первом запуске Windows скачивает pyserial, если библиотека ещё не установлена.

## Запуск на Mac

В этой рабочей копии всё установлено. Открыть `start-air.command` или выполнить:

```bash
/Users/timurkh/Desktop/BAS/through-interference/start-air.command
```

Эта консоль открывает только CANable. Надпись `БОРТ ПОЛУЧИЛ` означает фактический CAN-кадр, пришедший в CANable от бортового ESP32.

## Запуск на Windows

1. Перенести архив `CAN-two-computers.zip` на Windows и распаковать целиком, например в `C:\CAN-test`. Запускать из распакованной папки.
2. Если Python не установлен, поставить Python 3.10+ с pip и Python launcher: https://www.python.org/downloads/windows/ . IDE и PlatformIO для этой проверки не нужны.
3. Подключить наземный ESP32 по USB и открыть `start-ground.bat`. При первом запуске он создаёт локальное окружение `.console-venv` и устанавливает только pyserial. COM-порт единственного CH340 выбирается автоматически.
4. Если порт не найден, проверить в диспетчере устройств раздел "Порты (COM и LPT)". Для CH340/CH341 официальный драйвер: https://www.wch-ic.com/downloads/CH341SER_EXE.html . Устанавливать драйвер нужно, если Windows не определила устройство.
5. Если CH340 несколько, открыть терминал в распакованной папке и указать порт платы, например:

```bat
start-ground.bat --port COM5
```

Другой номер COM-порта берётся из диспетчера устройств. Консоль открывает только USB наземного ESP32, CANable и его драйвер на Windows не нужны.

## Что вводить

На Windows:

```text
send 00010203
```

На Mac должно появиться:

```text
БОРТ ПОЛУЧИЛ | ID=123 | DLC=4 | DATA=00010203
```

На Mac отправить ответ:

```text
send 04050607
```

На Windows должно появиться:

```text
КОМПЬЮТЕР ПОЛУЧИЛ | ID=123 | DLC=4 | DATA=04050607
```

Время выводится перед каждой строкой. Вводить без кавычек и обратных апострофов. До 8 байт за отправку, то есть 16 HEX-цифр. `stat` на Windows показывает состояние радио, `LINK=UP` означает установленную радиосвязь. На Mac `stat` показывает подключение CANable, состояние радио через него недоступно. `exit` закрывает консоль.

Строка `ОТПРАВИЛ` подтверждает локальную передачу в адаптер или очередь ESP32. Для проверки прохождения всего пути нужна строка `ПОЛУЧИЛ` на другом компьютере. В этом тесте CANable играет роль БВС, реальный полётный контроллер не участвует.
