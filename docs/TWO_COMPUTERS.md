# Проверка на двух компьютерах

Актуальная инструкция находится в [README, раздел 4](../README.md#4-демонстрация-на-двух-компьютерах).

```text
Компьютер земли ↔ USB-UART ↔ ESP32 TX ↔ радио ↔ ESP32 RX ↔ CAN-трансивер ↔ CANable ↔ компьютер борта
```

На земле запустить `./start-ground.sh`, на Linux со стороны CAN `./start-air.sh --can-channel can0`. На macOS со стороны CAN: `./start-air.sh`, без --can-channel. Все файлы проекта переносить целиком; окружение Python создаётся на каждом компьютере отдельно.

На земле в can> ввести `send 00010203`; на стороне CAN дождаться `БОРТ ПОЛУЧИЛ | ID=123 | DLC=4 | DATA=00010203`. Затем на стороне CAN ввести `send 04050607`; на земле дождаться `КОМПЬЮТЕР ПОЛУЧИЛ | ID=123 | DLC=4 | DATA=04050607`.

На Linux консоль стороны CAN можно заменить парой терминалов candump/cansend. GUI земли использует UART, как и ground-консоль. Одна программа должна владеть USB-UART портом в каждый момент.
