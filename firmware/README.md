# Готовые прошивки

Для установки готовых файлов не нужно собирать исходники или устанавливать PlatformIO. Нужны USB-кабель, Python и программа записи esptool.

- [2.0.1-CAN-E22](2.0.1-CAN-E22/): обычная ESP32 DevKit / ESP32-WROOM, 4 МБ Flash, E22-900M30S. Установка и проверка OCP 140 мА, максимальная настройка чипа PWR 22.
- [Полная инструкция прошивки земли и борта](../docs/MAX_POWER.md).
- [Объяснение исправления и чисел 22 / 30 / 140](../docs/POWER_FIX.md).

Сборка `ground` соответствует цели PlatformIO `tx`, сборка `air` цели `rx`. Используй файлы одной версии для обеих плат. Копии памяти реальных плат и их ключи в эту папку не добавляются.
