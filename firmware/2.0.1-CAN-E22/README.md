# Прошивка 2.0.1-CAN-E22

Для обычной ESP32 DevKit / ESP32-WROOM с 4 МБ Flash и E22-900M30S. Дата сборки комплекта: 19 ноября 2026 года.

**Начни с [пошаговой инструкции](../../docs/MAX_POWER.md).** Она включает подготовку питания, определение портов, резервное копирование, запись файлов, настройку и проверку. [Объяснение исправления](../../docs/POWER_FIX.md) описывает, почему нужно задать 22, а не 30.

| Папка | Какая плата | Цель PlatformIO |
| --- | --- | --- |
| `ground/` | Земля | `tx` |
| `air/` | Борт | `rx` |

В каждой папке находятся четыре файла:

| Файл | Адрес записи |
| --- | --- |
| `bootloader.bin` | `0x1000` |
| `partitions.bin` | `0x8000` |
| `boot_app0.bin` | `0xe000` |
| `firmware.bin` | `0x10000` |

Параметры записи: ESP32, DIO, 40 MHz, 4 MB. Используй готовые команды из инструкции. Отдельная запись этих файлов не затрагивает NVS `0x9000–0xDFFF` в штатной разметке проекта. Сохранённые настройки проверяются до SAVE; стирание всей памяти для обычного обновления не требуется.

`manifest.json` содержит адреса, размеры, SHA-256 файлов и контрольные суммы исходников прошивки. `SHA256SUMS.txt` позволяет проверить целостность комплекта; пути в нём отсчитываются от этой папки.

После прошивки максимальная настройка задаётся командой `PWR 22` и сохраняется через `SAVE`. Прошивка проверяет OCP 140 мА чтением из чипа. Значение по умолчанию остаётся 20. Фактическая RF-мощность не измерена; реальные платы при подготовке комплекта не прошивались.
